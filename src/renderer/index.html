Autorizar a instalação do cabo de áudio

Para o som sair no Discord, o Windows precisa de um microfone virtual. Sem ele, o soundFrog toca apenas no seu fone.

1
O instalador da VB-Audio abre Uma janela chamada "VB-CABLE Driver Setup". Clique em Install Driver.
2
O Windows pede permissão Instalar driver exige administrador. Confirme o aviso.
3
Reinicie o computador Só depois do reinício o Windows reconhece o dispositivo.

VB-CABLE é da VB-Audio Software, incluído sem modificações com autorização do autor. É donationware — .
